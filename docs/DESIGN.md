# 디자인 시스템

토스의 공개 디자인 원칙·UX 라이팅 원칙과 TDS(Toss Design System)의 공개 문서를 분석해 패턴과 수치를 참고한 자체 UI다.
토스의 로고·상표·서체·컴포넌트 코드·화면 이미지는 쓰지 않는다. 토큰은 `web/src/styles/tokens.css`가 유일한 출처다.

## 토스 레퍼런스 분석과 적용 (2026-10-27)

### 문구

- 명령형 "~하세요"를 "~해 주세요"(요청)나 "~할 수 있어요/~해 보세요"(제안)로 바꿨다. "글자 수는 이렇게 세요"처럼 '세다'의 해요체는 그대로 둔다
- 주 화면에 환경변수 이름을 쓰지 않는다. "서버의 실게시 허용(PUBLISHING_ENABLED)이 꺼져 있어요" → "실제 게시가 꺼져 있어요 (서버 설정)". 변수 이름은 연결 화면의 보조 줄(작은 고정폭 글자)과 운영 문서에만 둔다
- 이 서비스는 브라우저로 쓰는 웹이라 화면 문구의 "앱이 ~" 주어를 빼거나 "여기"·"이 서비스"로 바꿨다
- 한 문장에 하나만. 긴 설명(예: 사용량 화면 부제)은 핵심만 남기고 세부는 카드 안 캡션으로

| 본문 글자 | `#191F28` | `#E4E4E5` | 카드 위 16.6:1·12.7:1 |
| 보조 글자 | `#4E5968` | `#C3C3C6` | 회색 면 위 6.5:1·7.9:1 |

| 상태(성공·주의·위험) 글자 / 면 | `#0B7A52`/`#E5F7EF` · `#9A5B00`/`#FFF3E0` · `#C8283B`/`#FFEEEE` | `#4CC790`/`#16302A` · `#F0B45A`/`#33280F` · `#FF7A85`/`#3A1D24` | 각 면 위 4.8:1 이상 |

상태 표시는 색만으로 구분하지 않는다. `Badge`가 아이콘 + 상태 이름을 함께 쓴다.

## 레이아웃

- 화면 머리(TDS Top): 탭 화면은 "제목 ↔ 행동·알림" 한 줄 + 설명. 하위 화면은 위 내비게이션 줄(뒤로 · 행동 · 알림) 아래에 큰 제목과 설명을 화면 폭 전체로 둔다. 뒤로·알림 아이콘은 안쪽 여백만큼 바깥으로 빼서 화살표가 글자 왼쪽 선에 맞는다
- 왼쪽 선은 두 개만: 화면 여백 선(화면 제목·영역 제목·카드 가장자리)과 카드 안쪽 선(카드 내용·카드 안 목록 글자). 카드·시트 안 `RowGroup`은 상자 없이 그 여백에 글자를 맞춘다(`--row-pad-x`)
- 영역 제목 줄은 제목과 오른쪽 행동(예: 예약 전체)을 세로 가운데로 맞추고, 설명은 그 아래 줄에 둔다
- 선택 카드(ChoiceList)는 회색 배경 위에서는 테두리 없는 흰 카드, 카드·시트 안에서는 옅은 테두리
- 시트 아래 버튼은 구분선 없이 56px 큰 버튼 하나 또는 둘(TDS BottomCTA)

- 1024px 미만: 하단 탭(홈·콘텐츠·예약·설정, 아이콘 + 한글 라벨), 탭 높이 + safe-area만큼 본문 아래 여백
- 1024px 이상: 같은 네 메뉴 + 알림을 왼쪽 내비게이션으로
- 상세 편집·첫 설정은 하단 탭을 숨기고 전체 화면으로 쓴다. 첫 설정은 주 행동을 화면 아래 `BottomCTA`에 고정한다
- 시트: 모바일은 아래에서 올라오는 시트, 768px 이상은 가운데 대화상자. 포커스를 가두고 Esc로 닫으며 닫으면 원래 위치로 포커스를 돌린다
- 토스트는 잠깐 보이는 확인용, 계속 남아야 하는 문제는 알림함
- 목업 모드·오프라인은 상단 띠로 항상 보인다(화면 안에서 다시 반복하지 않는다)
- `prefers-reduced-motion`이면 전환을 끈다
