# 디자인 시스템

토스의 읽기 쉬운 위계·짧은 설명·명확한 행동, modo 화면의 넉넉한 여백·둥근 카드·단순한 설정 행을 참고한 자체 UI다.
다른 서비스의 로고·상표·컴포넌트는 쓰지 않는다. 토큰은 `web/src/styles/tokens.css`가 유일한 출처다.

## 색과 대비

시작 토큰(#F5F6F8·#191F28·#3182F6·#121214·#1C1C20)에서 WCAG 대비를 확인해 조정했다.

| 용도 | 라이트 | 다크 | 확인 |
|---|---|---|---|
| 배경 / 카드 | `#F5F6F8` / `#FFFFFF` | `#121214` / `#1C1C20` | 다크는 푸른 기가 없는 중성 회색 |
| 본문 글자 | `#191F28` | `#ECECEF` | 카드 위 16:1 이상 |
| 보조 글자 | `#4E5968` | `#B0B3BA` | 카드 위 7:1 이상 |
| 3차 글자(캡션) | `#6B7684` | `#8F939C` | 카드 위 4.5:1 이상 |
| 주 버튼 배경 | `#1E6AE0` (흰 글자) | `#1E6AE0` (흰 글자) | 5.0:1. 시작값 `#3182F6`은 흰 글자 대비 3.6:1로 본문 크기 기준 미달이라 한 단계 어둡게 |
| 링크·강조 글자 | `#1B5FCA` | `#6EA2F7` | 카드 위 4.5:1 이상 |

상태 표시는 색만으로 구분하지 않는다. `Badge`가 아이콘 + 상태 이름을 함께 쓴다.

## 레이아웃

- 1024px 미만: 하단 탭(홈·콘텐츠·예약·설정, 아이콘 + 한글 라벨), 탭 높이 + safe-area만큼 본문 아래 여백
- 1024px 이상: 같은 네 메뉴 + 알림을 왼쪽 내비게이션으로
- 상세 편집·첫 설정은 하단 탭을 숨기고 전체 화면으로 쓴다
- 시트: 모바일은 아래에서 올라오는 시트, 768px 이상은 가운데 대화상자. 포커스를 가두고 Esc로 닫으며 닫으면 원래 위치로 포커스를 돌린다
- 토스트는 잠깐 보이는 확인용, 계속 남아야 하는 문제는 알림함
- 목업 모드·오프라인은 상단 띠로 항상 보인다
- `prefers-reduced-motion`이면 전환을 끈다
