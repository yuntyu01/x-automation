- 결정 기록: `docs/ARCHITECTURE.md`
- 검증: `go vet`·`staticcheck`·`go test ./...` 통과, `tsc -b`·`eslint`·`vite build` 통과, 서버 실행 후 `/healthz` 200, `/contents/abc` → index.html 200, `/assets/nope.js` 404
